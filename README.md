# ImageLite API

API REST para cadastro de usuários e gerenciamento de imagens. Desenvolvida como parte do projeto ImageLite.

## Tecnologias

- Java 17
- Spring Boot
- Spring Security e JWT
- Spring Data JPA
- PostgreSQL
- Maven
- Docker

## Funcionalidades

- Cadastro e autenticação de usuários
- Autenticação das rotas protegidas com JWT
- Envio, busca e visualização de imagens
- Filtro de imagens por nome, tags e formato
- Armazenamento dos arquivos no PostgreSQL
